# Backlog Roulette

A tiny browser toy for the nights where choosing a game takes longer than actually playing one.

Add whatever is sitting in your backlog, hit **Pick one**, and live with the result. Or hit **nah, reroll**. I'm not your dad.

## What it does

- keeps your backlog in `localStorage`
- ignores duplicate titles
- avoids picking the exact same game twice in a row when possible
- lets you remove individual games or wipe the list
- works without an account, backend, framework, or build step
- includes keyboard-friendly controls and polite result announcements

## Run it

Clone the repo and open `index.html` in a browser.

That's it. No install step.

## Why this exists

Because I have an absolute autistic monkey of a friend who spent more time deciding what to play than playing anything.

This is intentionally small. If a feature makes the picker more useful without turning it into backlog-management software, it probably belongs here.
